        What's running in this tab

        This game runs a real ClickHouse database inside your browser. It's chDB, compiled to WebAssembly and running in a Web Worker. There's no game server and no account, and nothing you type leaves this tab.

        Every line you read and every choice you make is stored as one wide event: who was talking, what you picked, how long you hesitated, and anything else worth keeping. Events go to your browser's storage first, and that log is your save file. Export it from the menu and it's a JSONEachRow file you can query yourself.

        When the game loads, it replays your log into ClickHouse. From then on, every branch in the story is a SQL query. The three pillars are views over the same table: Metrics keeps totals and drops the words, Traces sees a 1% sample plus anything you mark as important, and Logs keeps every word without knowing what any of it meant.

        Switch on SQL in the toolbar to watch the query behind each branch as it runs. Later on, you get a shell of your own.
